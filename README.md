## 작성 방식

필사를 바탕으로 **읽은 흐름 → 궁금했던 점 → Q&A → 예시·추가 조사**를 남김.
음슴체로 쓰며, 💭 내 생각과 🔎 GPT 해설·추가 조사는 관련 대목에 붙임.
핵심은 간결하게 쓰되 질문의 맥락과 이해에 필요한 설명은 줄이지 않음.

글은 `posts/week-XX/README.md`에 작성하고, 원본 메모·Q&A는 같은 폴더에 보존함.
변경을 검토한 뒤 `main`에 직접 커밋함. 브랜치·PR·병합은 요청받은 경우에만 진행함.
